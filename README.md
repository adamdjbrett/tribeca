# Tribeca (Eleventy Port)

Eleventy `3.1.5` port of the original TryGhost Tribeca theme.

## Credit

- Original theme: `TryGhost/Tribeca`
- This repository is an Eleventy/Handlebars port.

## Stack

- Eleventy `3.1.5`
- Handlebars templates
- Luxon date filters

## Commands

```bash
npm install
npm run start
npm run build
```

## Routes

- `/`
- `/posts/:slug/`
- `/tags/` and `/tags/:tag/`
- `/authors/` and `/authors/:author/`
- `/feed/feed.xml`
- `/sitemap.xml`
- `/robots.txt`
- `/humans.txt`
- `/about/`, `/contact/`, `/404.html`
